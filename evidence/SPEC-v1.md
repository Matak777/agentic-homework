# SPEC

## Requirement

Исправить пустые названия задач. На доске не должно быть пустых строк, а счётчик должен считать только видимые открытые задачи.

## Acceptance tests

- **R1:** пустое переименование не сохраняется, старое название остаётся, появляется «Название не может быть пустым». Пробел, таб, U+00A0 и их смеси считаются пустотой. Такие названия нельзя и создать. У нормального названия края обрезаются, внутри ничего не меняется. Отмена ничего не меняет.
- **R2:** старые пустые задачи скрыты во всех фильтрах, но остаются в данных.
- **R3:** счётчик совпадает со списком открытых. На исходной доске — 1.

## Non-goals

Не менять дизайн, зависимости и исходные задачи. Не удалять старые данные и не добавлять новые функции.

## Files in scope

Реализация: `src/tasks.ts` и `src/App.tsx`.

## Definition of done

Тесты написаны до исправления; агент их не читает. `npm test` и `npm run build` проходят. Есть скриншот, журнал и отчёт. Первые три поломки дают красные тесты, после проверки код восстановлен.
